# TOEFL Slang Master - Project Vision

## 核心定位

本项目**不是**一个单纯的 prompt 集合，也**不是**临时拼凑出来的英语工具箱。

本项目的长期目标，是逐步演化为一个 **面向华语学习者的英语学习 pipeline 平台**。
这个平台当前以 CLI 为主，不追求先做 GUI，也不追求先做 SaaS。

其核心价值在于：把语言学习过程中的不同任务，收拢为一条稳定、可复用、可持续推进的流水线。

## 终极愿景

项目的终极形态是一个 **CLI-first、Markdown-first、contract-first、locale-aware** 的英语学习系统。

终极状态下，用户可以完成三类事情：

1. **输入学习**：
   输入一篇外刊、PDF、Markdown 或文本材料，系统提取结构化笔记、重点表达、可迁移句式，并进一步生成可复习的表达卡 (Expression Card)。

2. **输出纠偏**：
   输入一段作文、段落或句子，系统提供结构化诊断，并提取弱表达 (Weak Expressions)，自动送入表达升级链路 (Dictionary Pro)。

3. **双语/多语支持**：
   全流程的展示和解释支持简体中文 (zh-Hans)、繁体中文 (zh-Hant) 或英文，同时保持底层 schema、contract、枚举值和内部标识统一为纯英文。

## 我们“不”做什么（当前阶段）

- 不先做复杂的 GUI 或 Web 前端
- 不先开发独立的手机 App
- 不做花哨的用户长期记忆算法或动态数据库前端
- 不把系统拆解为零散的 prompt 集合

## 核心指导思想

- **结构化输出优先**：所有智能交互的落地必须是稳定的 JSON 和可复用的 Markdown。
- **Contract-first**：各模块间的通信基于稳定的对象契约，而不是 prompt 到 prompt 的直接拼接。

---
> **核心口号**
> 我们要做的是：**一个能把素材输入、表达升级、写作诊断三件事稳定串起来的英语学习 pipeline 平台。**
