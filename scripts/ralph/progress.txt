## Key Learnings

1. **Workspace model contracts work**: CLI and GUI share the same event/artifact types with zero duplication.
2. **ALET tokens keep the design coherent**: A small set of CSS variables (--surface-light, --accent-workspace, --grid-line) prevented ad-hoc color sprawl across 12+ pages.
3. **Incremental typecheck is essential**: Running typecheck after each story caught import errors immediately rather than accumulating silent drift.
4. **CSS cleanup is low-risk, high-reward**: Removing 5 dead class blocks freed ~100 lines and reduced cognitive load.
5. **Empty states deserve design**: The transition from raw placeholder text to workspace-empty-state classes made the app feel intentional before any command is run.
